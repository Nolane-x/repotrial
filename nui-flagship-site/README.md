# NUI Flagship Experiential Website — M2

A standalone GitHub-CI sandbox implementation of the **Living Intelligence / Cinematic Chapter Identity** direction. This code intentionally lives outside `Nolane-UI-Intelligence`; that repository is read-only design/skill authority for this build.

## M2 experience

The same Nolane Intelligence Field now gains materially different chapter identities while remaining one continuous system:

- **Silence** — restrained spectral seed and quiet authority.
- **Awakening** — semantic relations and first propagation.
- **Cognitive Architecture** — seven domain territories and orbital structure.
- **Scale Break** — a controlled depth portal and forward scale release.
- **Intelligence in Motion** — causal pulses travel on real NUI semantic edges.
- **World Opens** — the field becomes an environmental spatial frame.
- **Cognitive Cathedral** — one deliberate visual climax with all domains, signals, shells and topology at peak scale.
- **Resolution Sigil** — network/orbit/signal energy collapses and exactly seven domain representatives converge into a compact Nolane sigil.

The scene is driven by one deterministic cinematic state so camera, portal, orbit, signal, network, atmosphere and sigil cannot drift independently.

## Stack

Next.js + TypeScript + React Three Fiber/Three.js + GSAP ScrollTrigger + Motion + custom GLSL.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Production verification:

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

## Evidence gates

- 8 semantic story beats exist in DOM independently of WebGL.
- Deterministic cinematic scene modes stay synchronized with the visible chapter.
- Signal routes use only real semantic edges from the NUI field model.
- Resolution contains one representative from each of the seven NUI domains.
- Climax expands while final resolution decisively reduces network/orbit/signal/atmospheric energy.
- Capability tiers reduce GPU density without deleting semantic content.
- `prefers-reduced-motion` removes large camera/ambient movement while preserving semantic progression and full copy legibility.
- Playwright validates scene sync, visual anchors, runtime console/page errors, mobile horizontal overflow, and desktop/mobile/reduced-motion rendered evidence.

A green build is necessary but not sufficient: final M2 delivery is accepted only after manual review of CI-rendered screenshots confirms escalation to one climax and a visibly quieter resolution.
