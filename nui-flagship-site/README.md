# NUI Flagship Experiential Website — M3 Spatial Metamorphosis

M3 evolves the verified M2 Living Intelligence flagship into **Spatial Metamorphosis**: one semantic NUI Intelligence Field physically changes topology across the story instead of swapping unrelated effects.

## M3 signature systems

- Deterministic `morph`, `fold`, `light`, `typeDepth`, and `pulse` story channels.
- Semantic-node deformation that preserves real NUI domain identity and edges.
- Pointer focus limited to a real node plus first-order semantic neighbors.
- Capability-tiered light ribbons derived from semantic geometry.
- Seven-domain Environmental Lattice for World Opens.
- DOM/WebGL choreography coupled through the same M3 scene state.
- **Impossible Fold** climax with split-shell geometry.
- Resolution collapses M3 deformation and returns to the seven-domain sigil.
- Reduced-motion retains semantic progression while clamping fold/camera/travel.

## Stack

Next.js + TypeScript + React Three Fiber/Three.js + drei + GSAP ScrollTrigger + Motion + Vitest + Playwright.

## Release gates

```bash
npm test
node tests/m3.source.cjs
node tests/m3.css.cjs
npm run build
npm run test:e2e
```

`npm test` includes a 401-sample geometry continuity/property gate so the Impossible Fold cannot silently regress into a visible topology snap.

GitHub Actions on `build/nui-flagship-ci` is the authoritative browser/build release gate and packages the verified M3 source plus rendered evidence.
